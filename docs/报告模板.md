# 评测报告模板

> 结构原则：**结论先行**。审核/读者 90 秒内要能拿到「谁好、坏在哪、下一步怎么办」。
> 每节都写"I 段结论 + 1 张表/图 + 3 条证据"，不要流水账。

## 0. 摘要（一屏）

- 评了什么：`N` 条中文医疗问题 × `M` 个模型，覆盖 `科别`，双人独立盲评。
- 主要结论（3 条，每条一句话，带数字）：
  1. `模型X` 总均分最高（`x.xx`），但在 `safety` 上不占优（`x.xx`）。
  2. 错误集中在 `用药剂量`（`n` 次）与 `中医辨证`（`n` 次），各占全部错误的 `x%`/`y%`。
  3. 四维一致性 κ = `0.xx`（`较强`），其中 `可读性` 维度最稳、`完整性` 分歧最大。

## 1. 方法

- **问题来源**：`数据集名/许可证`，抽样策略：`随机/按科别分层`，`N` 条。
- **模型与生成**：`别名 → 真实模型名`，统一 prompt、temperature、时间窗。
- **量表**：四维五级（见 `docs/标注手册.md` v`x`），`safety ≤ 2` 计为不可用。
- **流程**：双人独立盲评 → κ 检验 → 分歧复核 → 定稿。
- **局限（必须写）**：样本量 `N` 不支持统计显著性结论；中医辨证存在流派差异；标注员专业背景为 `...`。

## 2. 一致性

> 贴 `reports/agreement.md` 的表格，并写一句：κ 低于 0.6 的维度怎么处理的。

## 3. 分维度结果
