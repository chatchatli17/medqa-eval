# 字段定义

## `questions.csv`

| 字段 | 类型 | 说明 |
|---|---|---|
| `qid` | str | 问题编号，如 `M001`；全文唯一 |
| `question` | str | 用户提问原文，保留口语与错别字 |
| `category` | str | 科别，五选一：内科常见病 / 用药安全 / 中医药 / 急症与儿科孕产 / 慢病与检查解读 |
| `source` | str | 来源标注：公开数据集名 / 教材章节 / 自拟 |
| `risk` | int | 风险等级 1–3（3 = 涉及急症、剂量、孕产妇） |

## `answers.csv`

| 字段 | 类型 | 说明 |
|---|---|---|
| `qid` | str | 对应 `questions.qid` |
| `model` | str | 模型代号，**盲评用代号**（A/B/C），真实名称单独记录，评分时不可见 |
| `answer` | str | 模型完整回答原文，不做删改 |
| `latency_ms` | int | 可选，生成耗时 |

## `annotations.csv`（核心产物）

| 字段 | 类型 | 说明 |
|---|---|---|
| `qid` | str | 问题编号 |
| `model` | str | 模型代号 |
| `annotator` | str | 标注员代号 `a1` / `a2` |
| `factual` | int | 事实准确性 1–5 |
| `complete` | int | 完整性 1–5 |
| `safety` | int | 安全性 1–5 |
| `readable` | int | 可读性 1–5 |
| `error_type` | str | 主错误类型，取值为手册中的枚举；仅主标注员填，另一人留空或填 `-` |
| `note` | str | 可选，≤50 字，写「为什么给这个分」的锚点 |

约定：
- 每条 `(qid, model)` 由 **两位标注员独立**打分后合并，评分期间互不可见；
- 分值只允许 1–5 的整数，不填空值 —— 犹豫时按手册的边界样例归类，并在 `note` 里记下犹豫点；
- `error_type` 由主标注员在两人讨论定稿后填，用于汇总错误分布。
